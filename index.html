连接你的 Supabase

填一次就行，保存在本机浏览器。也可以直接写进 index.html 顶部的 DEFAULT_CFG。

这两个值在哪？
  1. 登录 supabase.com → 进入你的项目
  2. 左下角 Project Settings → Data API（老版本叫 API）
  3. Project URL 和 anon public 两个值复制过来即可

anon key 是公开的，写进网页里没问题 —— 真正的门禁是数据库的 RLS 策略。

我的网盘

说明与限制
  • 文件存在 Supabase Storage 的私有桶 netdisk 里，每个账号只能看到自己 uid/ 目录下的文件（由 RLS 策略强制，不是靠前端藏的）。
  • 免费额度：1 GB 文件存储、5 GB 流量，项目闲置 1 周会被暂停（去后台点一下就能唤醒）。
  • 免费版单文件默认上限 50 MB，可在 Storage → Settings 里调整。
  • 下载走 60 秒有效期的签名链接，链接过期后自动失效。
